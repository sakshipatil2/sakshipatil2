## 🚀 Featured Projects

### 🌫️ [Urban Air Quality Intelligence for Smart City Intervention](https://github.com/sakshipatil2/Urban-Air-Quality-Intelligence-for-Smart-City-Intervention)
AI-powered platform combining geospatial analytics, machine learning, and satellite-style
data to predict AQI, surface pollution hotspots, and support smart-city decisions. Ships a
FastAPI backend (mock-but-realistic data, structured for future live provider integration)
and a React/TanStack Start dashboard with maps, forecasts, and enforcement tooling.
**Tech:** `FastAPI` · `Python` · `React 19` · `TanStack Start/Query` · `TypeScript` · `Leaflet` · `Tailwind CSS`

### 💳 [AI Revenue Recovery — Razorpay Intent Rescue](https://github.com/sakshipatil2/AI-Revenue-Recovery)
Consent-first payment-recovery platform that decides whether to retry, repair, restructure,
or stop after a failed payment — while preventing duplicate charges. A strict-TypeScript
npm-workspaces monorepo with a Fastify API, a React/Vite merchant dashboard, shared Zod
contracts, and Playwright e2e tests.
**Tech:** `TypeScript` · `Fastify` · `React` · `Vite` · `Zod` · `Prisma` · `Playwright`

### 🏥 [AI Healthcare System](https://github.com/sakshipatil2/AI-Healthcare_System)
A Flask-based web application (`app.py`, `history_model.py`, HTML templates, and a SQLite
database) built to support a healthcare-focused workflow, including patient history tracking.
**Tech:** `Python` · `Flask` · `SQLite` · `HTML/CSS`

### ☕ [Java Question Bank](https://github.com/sakshipatil2/java_question)
A collection of simple, foundational Java programs.
**Tech:** `Java`
